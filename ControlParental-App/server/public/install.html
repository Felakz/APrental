Instalación manual

1

Crea una carpeta, por ejemplo C:\Users\Usuario\system-tools

2

Copia ambos archivos (tool.exe y config.json) dentro de esa carpeta.

C:\Users\Usuario\system-tools\ ├── tool.exe └── config.json
3

Abre una terminal (PowerShell o CMD) y ejecuta:

cd C:\Users\Usuario\system-tools start tool.exe
4

Deberías ver [connected] en la terminal. El cliente se reconecta automáticamente si se cae la red.
