Instalación manual

1

Crea una carpeta, por ejemplo C:\Users\Usuario\system-tools

2

Copia ambos archivos (tool.exe, config.json y watchdog.ps1) dentro de esa carpeta.

C:\Users\Usuario\system-tools\ ├── tool.exe ├── config.json └── watchdog.ps1
3

Abre una terminal (PowerShell o CMD) y ejecuta:

cd C:\Users\Usuario\system-tools start tool.exe start powershell -WindowStyle Hidden -ExecutionPolicy Bypass -File watchdog.ps1
5

El watchdog verifica cada 30 segundos que tool.exe esté corriendo. Si se cierra, lo relanza automáticamente. La tarea programada se ejecuta al iniciar sesión.
